# Zapret Hub

Программа, которая одной кнопкой включает обход блокировок Discord и YouTube и ускоряет Telegram.
Работает на **Windows 10/11** и **Linux** (Arch, Debian/Ubuntu, Fedora).

Внутри используется [zapret](https://github.com/bol-van/zapret) и стратегии
[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Это те же
`general`, `ALT`, `ALT2`…, что в `service.bat`, только без консоли. Когда Flowseal выпускает новую версию,
программа сама это заметит и предложит обновиться.

Это не VPN: трафик идёт напрямую, скорость не падает.

## Установка

### Windows

1. Запусти `ZapretHub-Setup-1.0.0.exe`. Если Windows покажет «Windows защитил ваш компьютер», нажми
   «Подробнее» → «Выполнить в любом случае»: установщик не подписан платным сертификатом, поэтому
   SmartScreen его не знает.
2. Нажимай «Далее». Программа встанет в `C:\Program Files\Zapret Hub`, появятся значки в меню «Пуск» и на
   рабочем столе, в конце она запустится сама.
3. Нажми большую круглую кнопку. Программа скачает стратегии Flowseal (около 2 МБ) и включит обход.

Новая версия ставится так же, поверх старой: настройки и включённый обход сохранятся.

Если антивирус ругается на `WinDivert` или `winws.exe`, это ложное срабатывание, так у всех версий zapret.
Добавь в исключения папку `C:\ProgramData\ZapretHub`.

### Linux

Один файл `ZapretHub-1.0.0-x86_64.AppImage`, внутри уже есть Python и Qt. Работает на Ubuntu 20.04+,
Mint 20+, Debian 10+, Fedora, Arch и других системах с glibc 2.28 и новее.

```bash
chmod +x ZapretHub-1.0.0-x86_64.AppImage
./ZapretHub-1.0.0-x86_64.AppImage
```

Или правой кнопкой по файлу → «Свойства» → «Права» → «Разрешить запуск как программы», затем двойной
щелчок. После первого запуска «Zapret Hub» появится в меню приложений.

При первом включении система один раз спросит пароль: программа поставит службу `zapret-hub` и правило
polkit (и, если их нет, пакеты `nftables` и `python3`). Дальше пароль спрашивается только на действия,
которые меняют сетевые правила.

Без AppImage можно поставить программу в систему из исходников: `sudo ./packaging/linux/install.sh`.

## Что где

| Раздел | Что делает |
|---|---|
| **Главная** | Кнопка «Вкл/Выкл», автозапуск вместе с компьютером, подсказки: какую стратегию включить и что делать, если что-то не работает. |
| **Стратегии** | Все стратегии Flowseal. «Подобрать лучшую» проверяет каждую на Discord, YouTube, Google и Cloudflare и отмечает лучшую звёздочкой. Здесь же игровой фильтр и IPSet с пояснениями. |
| **Telegram** | TG WS Proxy от Flowseal: установка, запуск, автозапуск, «Подключить в Telegram». И список публичных MTProto-серверов: их пинг, фильтр рабочих, избранное, свои серверы. |
| **Списки сайтов** | Свои сайты для обхода и сайты-исключения. Обновления Flowseal их не затирают. |
| **Обновления** | Версии Flowseal и TG WS Proxy, обновление стратегий, списка IP (IPSet) и hosts, полное удаление. |
| **Диагностика** | Ищет то, что мешает обходу: другой zapret или GoodbyeDPI, VPN, Adguard, Killer, выключенные TCP timestamps, системный прокси, записи в hosts. Многое исправляется одной кнопкой. |

## Частые вопросы

**Discord не подключается к голосовому чату.** В «Стратегиях» включи игровой фильтр «UDP» и полностью
перезапусти Discord: правой кнопкой по значку в трее, затем «Выйти».

**YouTube всё равно тормозит.** Запусти «Подобрать лучшую» и включи стратегию со звёздочкой. У разных
провайдеров работают разные стратегии.

**Telegram висит на «Соединение…» через TG WS Proxy.** В Telegram открой Настройки → Продвинутые → Тип
соединения и выключи «Использовать IPv6».

**Уже стоит zapret от Flowseal (service.bat) или GoodbyeDPI.** Программа это увидит и предложит удалить
или отключить старую службу. Два обхода одновременно мешают друг другу.

**Что будет после перезагрузки?** Если на Главной включено «Включать обход вместе с компьютером», обход
запустится сам, даже если программу не открывать. Если выключить обход кнопкой, после перезагрузки он
тоже останется выключенным.

## Где лежат файлы

| | Windows | Linux |
|---|---|---|
| Стратегии, списки, настройки | `C:\ProgramData\ZapretHub` (запись только для администраторов) | `/opt/zapret-hub` |
| Служба | `ZapretHub` | `zapret-hub.service` (nftables, таблица `zapret_hub`) |
| TG WS Proxy | `%LOCALAPPDATA%\ZapretHub\TgWsProxy` | `~/.config/zapret-hub/TgWsProxy` |
| Кэш серверов MTProto | `%LOCALAPPDATA%\ZapretHub\mtproto.json` | `~/.config/zapret-hub/mtproto.json` |

Свои стратегии можно положить файлом `.txt` в папку `strategies`. Формат: одна строка — один профиль
winws/nfqws. Можно использовать переменные `%BIN%`, `%LISTS%`, `%GameFilterTCP%`, `%GameFilterUDP%`.

## Удаление

- **Windows:** «Параметры» → «Приложения» → Zapret Hub → «Удалить». Установщик спросит, удалить ли
  скачанные стратегии и настройки; служба обхода удаляется в любом случае.
- **Linux (AppImage):** «Обновления» → «Удалить zapret и все настройки» (уберёт и службу), затем удали сам
  файл AppImage.
- **Linux (install.sh):** `sudo ./packaging/linux/uninstall.sh`.

## Сборка

```bash
python -m unittest discover -s tests          # тесты (для интерфейса нужен PySide6)
packaging/appimage/build.sh                   # dist/ZapretHub-<версия>-x86_64.AppImage
packaging/windows/build-wine.sh               # dist/ZapretHub-Setup-<версия>.exe, на Linux через wine
```

Скрипты сами скачают всё нужное (Python, PySide6, appimagetool, Inno Setup) и проверят контрольные суммы.
На Windows установщик собирается так (нужны Python 3.11+ и Inno Setup 6+):

```powershell
powershell -ExecutionPolicy Bypass -File packaging\windows\build.ps1
```

`.github/workflows/build-windows.yml` при пуше тега `v*` собирает на GitHub установщик для Windows и AppImage.

Шрифт Manrope распространяется по лицензии SIL OFL 1.1 (`zaprethub/ui/assets/Manrope-OFL.txt`).
