# Zapret Hub — дизайн

## Зачем

Программа для друга (не для себя): одной кнопкой включить обход блокировок
Discord / YouTube / Telegram на **Windows и Linux**, без консольных .bat и меню
`service.bat`. Основа — стратегии [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube),
которые программа подтягивает сама, когда Flowseal выпускает новую версию.
Плюс Telegram: TG WS Proxy от Flowseal и список публичных MTProto-серверов.

Пользователь — не технарь. Поэтому везде подсказки простыми словами
и рекомендации («Рекомендуем: …», «Не работает Discord? Попробуй …»).

Уже есть `~/Work/zapret-gui` (GTK4, только Arch) — из него переносится логика,
сам он не меняется.

## Цели

1. Один код, два ОС. Windows: `.exe` (просит права администратора сам). Linux: Arch, Debian/Ubuntu, Fedora.
2. Главная: большой переключатель Вкл/Выкл, текущая стратегия, статус, рекомендации, предупреждения о конфликтах.
3. Стратегии: все general*.bat Flowseal, выбор, игровой фильтр, IPSet (none/any/loaded) — с пояснениями.
   Тест всех стратегий (сайты + задержка), лучшая подсвечивается, «Включить рекомендуемую».
4. Telegram:
   - TG WS Proxy (Flowseal): установка/обновление (SHA-256), запуск/стоп, автозапуск, «Подключить» (tg:// ссылка).
   - Публичные MTProto: загрузка из нескольких источников, разбор tg:// и t.me ссылок, дедупликация,
     проверка доступности (TCP connect, время), сортировка, «Подключить», «Скопировать», избранное, свои серверы.
5. Списки: свои домены/IP для обхода и исключений (list-general-user, list-exclude-user, ipset-exclude-user).
6. Обновления: при запуске проверка версии Flowseal (`.service/version.txt`), баннер «Вышла 1.10.4 — Обновить»;
   обновление перекачивает стратегии/списки/bin, свои списки и стратегии не трогает; на Linux также bol-van/zapret;
   IPSet и hosts от Flowseal.
7. Диагностика: проверки из `service.bat` (Windows: BFE, системный прокси, TCP timestamps, Adguard, Killer,
   Intel Connectivity, Check Point, SmartByte, кириллица/OneDrive в пути, VPN-службы, Secure DNS, hosts,
   конфликт WinDivert / GoodbyeDPI / служба `zapret` от Flowseal). Linux: nft, nfqws, конфликт с zapret-gui/zapret.
   Каждая проблема — с кнопкой «Исправить», где это безопасно.
8. Красивый интерфейс: тёмная тема, боковое меню с иконками, карточки, подсказки `?`, иконка в трее.

## Не цели

- VLESS Reality, AmneziaWG и любые VPN — пользователь явно отказался.
- Самообновление самой программы (нет публичного репозитория).
- macOS.
- blockcheck.sh / ручной редактор стратегий из zapret-gui — не переносить (лишняя сложность для друга).
  Свои стратегии остаются возможными как файлы в папке custom.

## Анти-цели (провал, даже если «работает»)

- Друг не понимает, что нажать: нет подсказок, ошибки на английском/трейсбеки.
- После обновления Flowseal стратегии ломаются молча.
- Программа оставляет мусор: висящий WinDivert, службу, nft-таблицу, правку hosts без отката.
- Конфликт с уже установленным zapret Flowseal/GoodbyeDPI без предупреждения.

## Как устроено (решения)

- **Python + PySide6 (Qt6 Widgets)**, своя QSS-тема. Решение моё, пользователь согласился.
- Логика, общая для ОС (`core.py`): перенос из zapret-gui — разбор .bat (`bat_to_strategy`), сборка аргументов,
  плейсхолдеры `%BIN%`, `%LISTS%`, `%GameFilterTCP/UDP%`, порты, списки, цели тестов, hosts-блок.
- **Windows-бэкенд**: данные в `%ProgramData%\ZapretHub` (без кириллицы и OneDrive). Распаковка zip Flowseal.
  Запуск `bin\winws.exe` с аргументами стратегии (с `--wf-*`). Режим «служба» = `sc create ZapretHub binPath= …
  start= auto` как у Flowseal (работает без программы, после перезагрузки). Перед стартом: TCP timestamps,
  остановка конфликтов (с вопросом). Выключение — стоп службы, удаление WinDivert, если наш winws не работает.
- **Linux-бэкенд**: как zapret-gui — root-helper через pkexec, systemd-служба `zapret-hub.service`, nfqws из
  bol-van/zapret, nft-таблица `zapret_hub`, очередь 201 (не пересекается с zapret-gui=200). Данные в `/opt/zapret-hub`.
- **Тесты стратегий**: проверки на Python (http.client + ssl с TLS1.2/1.3), одинаковые на обеих ОС;
  на Linux выполняются в helper под root, на Windows — в процессе (программа уже админ).
- **MTProto-источники** (живые на 2026-10-19): kort0881/telegram-proxy-collector `proxy_ru.txt`, `proxy_all.txt`
  (обновляется ежедневно), SoliSpirit/mtproto `all_proxies.txt`, Grim1313/mtproto-for-telegram `all_proxies.txt`.
  Источники в конфиге, можно добавлять свои URL. Кэш списка — в профиле пользователя.
- **Сборка**: Windows — PyInstaller (папка + `ZapretHub.exe` с uac_admin-манифестом), собирается под wine
  скриптом `build-windows.sh`; плюс workflow GitHub Actions на будущее. Linux — `install.sh`, определяет pacman/apt/dnf,
  ставит PySide6 из репозитория дистрибутива, иначе pip в venv.
- Новый проект `~/Work/zapret-hub`, git.

## Оставлено исполнителю

Раскладка модулей, вид иконок/цветов, тексты подсказок, детали трея, таймауты проверок.

- Мелочи, решённые мной: на Windows программа запущена от админа, поэтому tg://-ссылки открываются через
  `explorer.exe`, чтобы Telegram не стартовал с правами админа; автозапуск TG WS Proxy — ключ `HKCU\…\Run`;
  zapret после перезагрузки поднимает служба, саму программу в автозапуск не кладём (опция).
- Все URL (GitHub API, raw) — в одном месте и переопределяются переменной окружения, чтобы тестировать с локального зеркала.

## Проверка

- Юнит-тесты: разбор .bat, сборка argv для winws/nfqws, команды `sc`, разбор MTProto-ссылок, сравнение версий.
- Linux — по-настоящему на этой машине (zapret-gui выключен, конфликтов нет).
- Windows — в ВМ «virus test» (libvirt, VNC, сеть `sandbox` без выхода в интернет): сборка exe под wine,
  копирование в ВМ, проверка запуска GUI, установки из локального зеркала релиза Flowseal, старта winws/WinDivert,
  создания/удаления службы, диагностики. Обход DPI в ВМ без интернета не проверить — только что всё запускается
  и корректно убирается за собой.
